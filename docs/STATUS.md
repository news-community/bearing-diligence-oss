# Status: what is proven, what is built, what is not

This file is the one place that claims anything about what the code does. Run `npm run check` to
reproduce every claim in the first table: it runs the tests, the code gates, the document checks,
the failing-case proof of each, and a smoke test of the real app, in a few minutes. Everything runs
under Electron's own Node, so there is one native build.

```
225 tests    12 code gates    8 document senses    51 of 51 guards caught when deleted
```

The line above is generated by `npm run counts`; nobody types it.

## In one sentence

Reading a folder, the change record, answers with a quoted passage under every sentence, refusals
and the desktop app all run end to end, tested on synthetic material and small folders of real
public agendas. **Nobody it is for has used it yet**, and no measurement here was made on more than
one machine.

## Built, and NOT proven

| What | Why not |
|---|---|
| Commitments and their pairings | 4 tests on synthetic text. The detector is a guess about how one body writes |
| The brief | assembled and rendered, reachable from a button on each document since 2026-09-28, and **its value to a reader is unmeasured** |
| The egress test | the procedure is written; **it has never been run**, and running it needs a packet filter and a control that fires |
| A signed, notarised installer | needs a Developer ID certificate that is not on this machine |
| The download module | pinned digests, a refusal for anything not in the manifest, and **no caller at all until 2026-09-22**. `npm run models` now runs it, and running it the first time found two defects in it. Nothing has been pulled by it: every pinned model was already held |
## Not built, on purpose

- **A scheduled downloader.** A document is added by putting it in the opened folder.
- **Any hosted path but answering, and any fallback.** Reading, the index, the change record and the
  source checks never reach the cloud module, and a gate fails the build if they could.
- **Machine notes.** Invariant 11 keeps a model's conclusion out of the record, so there is no store
  for one.

## Known limits

- **Measured on one Mac** (Apple silicon, 128 GB). Speeds and memory on other machines are estimates.
- **On a 16 GB machine no ranked research model fits**, and the reading model answers unless the
  person chooses another, including a hosted one. See [models.md](models.md).
- **The answer checks find what code can find**: figures, dates, names and outcome words that are not
  on the cited page. Whether a passage really supports a sentence is the reader's call, and the page
  says so.
- **macOS only** so far. Nothing is known to block Linux or Windows; nothing has been tried there.
